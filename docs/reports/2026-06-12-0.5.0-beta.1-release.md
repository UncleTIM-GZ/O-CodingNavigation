# Release report — o-coding-navigation@0.5.0-beta.1

> Date: 2026-06-12 · Tag: `v0.5.0-beta.1` · Channel: npm `latest` + `beta`（`alpha` 保留在 `0.1.0-alpha.2`）
> SOP profile: `default-ai-coding-sop@0.5.0`（不变——本版是引擎/CLI 增量，非 SOP bump）

## What's in this release

**Rewind & Cycle（DEC-033 / AM-008）** — 受控游标回拨与重开循环，封堵"游标只进不退"的三个 dogfood 缺口（中途升级越过台账生成点无恢复路径 / 终点步后无受控重开 / 手改 state.json 成为事实逃生通道）：

- `ocn rewind --to <stepId> --reason <text> [--json]` — 轮内回拨到严格更早的步骤；`--reason` 必填；docs/ 不动；`latestGateResult` 置空；回拨零豁免（之后每次 advance 重过完整门禁）。
- `ocn cycle new --yes [--json]` — 本轮运行时状态归档至 `.ocoding/cycles/<n>-<ISO-ts>/`（目录名即轮次号），游标归零重开；docs/ 保留供门禁快进；pin 与用户所有的 `config.yaml` 不变；审计 JSONL 不随轮归档——单链贯穿所有轮次。
- 终点步 `no_next_step` 拒绝消息双语指路两条合法去路。
- 审计事件新增 `cursor_rewind` / `cycle_started`（单事件类型，result success|failed）。
- 两命令均人类专属、CLI-only；MCP 白名单 7 工具不变。
- 命名裁决：回拨命名 `rewind`，`reset` 保留给冻结契约 §25 的删除式归零语义（§25 未动）。
