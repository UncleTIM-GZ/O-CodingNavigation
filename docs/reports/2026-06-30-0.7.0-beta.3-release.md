## What's in this release

**就绪门准时激活（AM-014 / DEC-040）—— 不提前且不缺失。** 修复 minimal 档干净 `ocn init` 在
**第一步**就被 8 条下游就绪检查拦死的悬崖。

- **不提前**：每条 block 检查的生效状态 `dueState(rule)` = 其输入里最晚到期的 SOP 状态
  （artifact 依赖→产出该文档的 step 所在状态；repo-probe→策略表）。`currentState < dueState` 判新判定
  `DEFERRED`，不阻断。
- **不缺失**：到期（`≥ dueState`）起每一关持续强制，复活后阻断直到满足——带未满足项**到不了 VERIFY**。
- **可见**：`DEFERRED` 在 `ocn brief` 显示为 "Forthcoming｜将到期 (not due until …)"、在 `ocn readiness list`
  显示为 `[DEFERRED]`，绝不静默隐藏。
- **失效安全**：任一依赖不可解析 → 不延迟（从第一关强制 = 改前行为），宁可早判不漏判。
- **opt-in、向后兼容**：规则手册开关 `precise_activation`；0.7.0 开，0.4.0/0.5.0 **逐字冻结**、行为不变。

引擎/CLI 特性，非 SOP bump（沿 AM-008/009 先例）；MCP 白名单 7 工具不变。
