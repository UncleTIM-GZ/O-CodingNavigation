## 1. Summary

This PR adds the `examples/plan-to-verify/` example project — the first
example that covers the **full** SOP 0.2.0 mainline. After this PR:

- `examples/plan-to-verify/docs/` ships 19 example artifacts (00–18),
  one per wired SOP 0.2.0 step from `step_project_brief` through
  `step_final_build_verdict`.
- `examples/plan-to-verify/scripts/smoke.sh` walks a fresh hermetic
  temp project from init through every wired step, asserts the SOP
  0.2.0 `state.json.project.sopProfileVersion`, runs `check` + `gate`
  + `advance` 19 times, and asserts that the terminal advance returns
  exit code 3 / `code: "ERR_STATE_MACHINE"`.
- The smoke is wired into `npm run test` via
  `tests/e2e/example-plan-to-verify.test.ts`, so CI exercises the
  example on every PR without modifying the CI workflow file.
- `examples/README.md` lists the new example as the **primary** SOP
  0.2.0 example and keeps `discovery-to-plan/` documented as the
  legacy demo.
- No npm publish, no `latest` movement, no version bump, no git tag,
  no GitHub Release, no GA promotion, no Cursor/Cline validation
  claim. No source / runtime / SOP / MCP-schema changes.

## 5. Smoke behavior

`examples/plan-to-verify/scripts/smoke.sh`:

1. Resolves the repo root from its own location and requires
   `dist/cli/index.js`. If `dist/` is missing it exits non-zero with a
   clear "run `npm run build` first" message — no auto-build inside
   the script.
2. Allocates a temp project with `mktemp -d -t ocn-plan-to-verify-`
   and registers a `trap` so the temp dir is removed on exit.
3. Runs `node dist/cli/index.js init --tier minimal` in the temp dir.
4. Reads the new `.ocoding/state.json`, asserts
   `project.sopProfileVersion == "0.2.0"`. Exits non-zero on mismatch.
5. Copies the example's 19 docs into the temp project's `docs/`.
6. Runs an iteration loop 19 times. Each iteration:
   - prints `ocn status`,
   - runs `ocn check --json` (must exit 0),
   - runs `ocn gate --json` (must exit 0),
   - captures the current `currentStepId` from `ocn status --json`,
   - if not the terminal step, runs `ocn advance --json` (must exit 0),
   - if the terminal step, runs `ocn advance --json` and asserts exit
     code 3 plus `code: "ERR_STATE_MACHINE"` — mirrors the contract
     pinned by `tests/cli/sop-0.2-full-flow.test.ts`.
7. Asserts the final `currentStateId/currentStepId` is
   `state_verify/step_final_build_verdict`.
8. Prints `Plan-to-verify smoke completed`.

Cleanup is unconditional via the `EXIT` trap.

## 6. CI / test integration

**Mechanism: vitest only.**

`tests/e2e/example-plan-to-verify.test.ts` is a vitest mirror of the
shell smoke. It uses the existing `spawnOcn` helper (which auto-falls
back to `tsx` when `dist/cli/index.js` is missing), so the test runs
against `dist/` in CI (where build precedes test) and against the TS
sources during local `npm run test` if dist is stale.

The test asserts:

1. `examples/plan-to-verify/docs/` ships exactly 19 markdown files in
   the FULL_PATH order.
2. `examples/plan-to-verify/scripts/smoke.sh` exists and is
   executable.
3. The full 19-step walk from a fresh `ocn init` through
   `step_final_build_verdict`, with the terminal advance returning
   exit code 3 / `ERR_STATE_MACHINE`.

The `.github/workflows/ci.yml` workflow is **unchanged**. The existing
job already runs `npm run lint`, `npm run typecheck`, `npm run build`,
then `npm run test:coverage` — vitest discovers the new test
automatically, and the build step ensures `dist/` is present so
`spawnOcn` uses the built binary path rather than tsx.
