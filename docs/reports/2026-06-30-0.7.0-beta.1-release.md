## What's in this release

**`ocn init` 默认接线 Claude Code（AM-013 / DEC-038）** —— 兑现 DEC-031 Out-of-scope 里预留的
`ocn init --with-agent` 后续，取**默认开 + `--no-agent` 退出**。

- **消坑**：堵掉最常见的 onboarding 陷阱——`ocn init` 后在 Claude Code 敲 `/ocn-next` 报
  `Unknown command`，因为斜杠命令文件 `.claude/commands/ocn-next.md` 是 `ocn agent setup` 写的、
  而这一步极易被忘。现在 init 默认顺带跑同一份幂等接线 core。
- **默认开，`--no-agent` 退出**：`ocn init --no-agent` 只写 `.ocoding/`，输出与改动前逐字一致。
- **失效安全**（沿 DEC-031 §1）：init 已成功 ⇒ 接线失败绝不让 init 失败，降级为
  "运行 `ocn agent setup --force`" 提示，退出码仍 0；init 自身被阻（如已初始化 exit 4）时不触发接线。
- **单一 CommandResult 信封**：复用 init 的 `data`（保留 `stateFile`/`currentStateId`…，text/JSON 渲染不变），
  附加 `data.agentSetup`（`{ ok, files }` 或 `{ ok:false, code }`）。
- **CLI 层编排**：core `initProject` 保持 agent 无关、不上 MCP 路径。**MCP 面零变化**：白名单恒 7 工具。

引擎/CLI 特性，沿 AM-008/009/010/011 先例不 bump SOP 版本。
