## What's in this release

**里程碑循环（milestone loop）用法固化** —— Lattice dogfood（P0→P1 交接）实战验证后写入 README 双语命令表，并刷新 npm 包内 README 快照：

- `ocn rewind` 行新增里程碑循环用法：完成边界含多个里程碑的项目，每个里程碑裁定后回拨至 `step_build_plan`、**追加**下一阶段 Task Specs（已完成任务规格原文保留——verify 命令不变 ⇒ 哈希不变 ⇒ done 保留）、重过门禁——任务台账成为项目级累积进度账（实战：19 done + 7 pending 共 26 任务）。
- `ocn cycle new` 行限定使用时机：本轮完成边界（01 范围）达成时收档；轮内逐里程碑迭代属 rewind 职权。
- 引擎行为审计确认该用法链无缺失：done 保留（id + 哈希双不变，`buildLedger`）、回拨后 `state_plan` 不误派发（有测试钉死）、出 BUILD 守卫只认 pending。
