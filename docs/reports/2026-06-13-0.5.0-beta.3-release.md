# Release report — o-coding-navigation@0.5.0-beta.3

> Date: 2026-06-13 · Tag: `v0.5.0-beta.3` · Channel: npm `latest` + `beta`（`alpha` 保留在 `0.1.0-alpha.2`）
> SOP profile: `default-ai-coding-sop@0.5.0`（**不变** —— Auto Mode 是引擎/CLI 特性，非 SOP bump）

## What's in this release

**可选自动模式（Auto Mode，AM-009 / DEC-034）** —— 首个让 AI 编码代理在人类显式授权后、按阶段自主推进 SOP 的能力。核心立场：**触发权可委托，裁决权永不委托**。

- `ocn auto on --phase <1|2|all>` / `off` / `resume` / `status` / `trace` —— 人工专属授权开关（拒绝 `OCN_ACTOR=ai_agent`），写 `auto_mode_changed` 审计；`status`/`trace` 为 pull 模式。
- **阶段委托**（按 advance 目标态归属）：第一阶段 = DISCOVERY→PLAN；第二阶段 = BUILD→VERIFY（含 `ocn task check` 与里程碑回拨 `rewind --to step_build_plan`）。PLAN→BUILD 跨界属第二阶段；SHIP/REFLECT 永不委托。
- **判定权零让渡**：每次 advance 仍跑完整门禁栈；任务完成仍只认冻结命令 exit 0。
- **熔断器**：同一步骤连续 N 次（默认 5）门禁失败即暂停自动模式（actor=system 审计），人工不受影响，`ocn auto resume` 解除。
- **决策痕迹三层**：ai_agent 调用强制 `--rationale`（背景/依据/操作）+ 引擎独立记录机器上下文（门禁结果、台账摘要、冻结命令、耗时）+ `ocn auto trace` 时间线复盘。
- **里程碑循环**：多 P 构建计划由 AI 自驱回拨→追加→重过门禁完成，已完成里程碑哈希保留。
- **动态治理文案**：`ocn brief` / `next-prompt` / agent 模板按授权切换；手动模式输出与 AM-009 之前逐字节一致。
- **硬禁区不变**：readiness waive / cycle new / sop upgrade / override / 非里程碑 rewind / `ocn auto` 本身，任何模式拒绝 AI。
- **MCP 面零变化**：白名单恒 7 工具（测试钉死）；自动模式完全 CLI-only。

引擎/CLI 特性，沿 AM-008（Rewind & Cycle）先例不 bump SOP 版本。详见 `docs/amendments/2026-06-13-auto-mode-amendment.md`。
