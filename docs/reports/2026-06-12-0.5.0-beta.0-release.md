# Release report — o-coding-navigation@0.5.0-beta.0

> Date: 2026-06-12 · Channel: npm `latest` + `beta` · Tag: `v0.5.0-beta.0`

**SOP 0.5.0 — Task Backbone（任务主干）** becomes the runtime default
(DEC-032 / AM-007). Closes the fourth false-completion class (receipt-only /
run-through, Lattice dogfood 2026-06-12): build plans now carry machine-
parseable Task Spec blocks; the build-plan gate validates six hard defects
and hash-freezes each task's verify command into `.ocoding/task-ledger.json`;
completion is decided only by `ocn task check` (frozen command exit 0);
`/ocn-next` dispatches pending tasks in `state_build`; `ocn advance` out of
BUILD is blocked while tasks are pending. New commands: `ocn task list`,
`ocn task check`. 0.4.0 frozen + importable; `ocn sop upgrade` migrates.

Gate: lint/typecheck/test green — 1079 tests / 130 files (+58). Docs:
DEC-032, AM-007 (+ index), accepted proposal `docs/task-backbone-proposal.md`,
README (EN+ZH) + CLAUDE.md + quickstart + mcp-usage + onepager.
