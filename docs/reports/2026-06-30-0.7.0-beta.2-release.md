# Release report — o-coding-navigation@0.7.0-beta.2

> Date: 2026-06-30 · Tag: `v0.7.0-beta.2` · Channel: npm `latest` + `beta`（`alpha` 保留在 `0.1.0-alpha.2`）
> SOP profile: **`default-ai-coding-sop@0.7.0`**（DEC-039 — 与 npm 包号统一）。
> 版本号：`0.7.0-beta.1 → 0.7.0-beta.2`（prerelease 递增）。

## What's in this release

**npm 与 SOP profile 版本统一 + 锁步（DEC-039）** —— 新增 SOP profile **0.7.0** 并设为运行时默认，
与 npm 包号对齐（**跳过 0.6.0** 直接对齐数字）。从此一个版本号贯穿 npm / `state.json` /
`config.yaml` / `sop.yaml` / MCP `detect_sop_version`。

- **内容等价、仅版本号变**：0.7.0 的 states/steps/artifact 路径/required sections/gates/readiness
  规则手册全部继承自 0.5.0（re-export），唯一差异是 `version` 字符串 0.7.0。`sop-loader.test.ts`
  钉死"0.7.0 与 0.5.0 仅版本号不同"。
- **pin 稳定不破**：0.5.0/0.4.0 等旧 profile 逐字冻结、仍可 `ocn init --sop-version <v>` 导入；
  已 pin 项目运行时行为不变，直到人工 `ocn sop upgrade`（默认 target 现为 0.7.0）。
- **锁步策略（今后）**：npm 与 SOP profile 同号推进；SOP 内容未变时新 profile 版本 re-export 旧内容。
- **MCP 面零变化**：白名单恒 7 工具。

引擎/CLI 切换，非 SOP 内容变更（沿 DEC-030/032 运行时切换先例）。

## Verification

- `prepublishOnly` 门通过：lint + typecheck + `test:coverage` + build。
- **1294** 单元/集成/e2e 测试全绿（新增"0.7.0 内容等价于 0.5.0"不变量测试；14 处运行时默认断言
  从 0.5.0 迁到 0.7.0）。
- 冒烟：干净 `ocn init` → `state.json` / `config.yaml` / `sop.yaml` / `status` 全报 0.7.0。
