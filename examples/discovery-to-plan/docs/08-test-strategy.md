## Layered approach｜分层方法

The example mirrors OCN's own 8-layer stack (`docs/07-api-contract.md` § Test layers):

1. **Unit** — pure functions (e.g. `gate-status`, `markdown-parser`, `result`).
2. **Schema** — zod parse/validate (`schema-*.test.ts`).
3. **Gate** — `runGate` and `checkCurrentArtifact` against fixtures.
4. **CLI** — spawn the built CLI in a temp project; assert exit codes + envelopes (`tests/cli/*`).
5. **Persistence** — `state.json` atomic write protocol.
6. **Lock** — file-lock acquire/release lifecycle (`LockLifecycleHook`).
7. **MCP** — tool registry + integration (Claude Desktop end-to-end in PR D).
8. **E2E** — full DISCOVERY → SPEC walk via `ocn advance` (`tests/e2e/skeleton-spike-demo.test.ts`).

## How this example tests itself｜本示例的自我验证

`scripts/smoke.sh` exercises the example end-to-end:

1. Allocate a `mktemp -d` temp project.
2. `ocn init` (canonical SOP snapshot generated by P1-003).
3. Copy this directory's `docs/` into the temp project.
4. Walk `ocn status` → `ocn check` → `ocn gate` → `ocn advance`, repeating advance until the SOP profile reports no further step.
5. Print final state / step. If the bundled templates change, the smoke surfaces the drift immediately.
